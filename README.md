# Py-MiniProject-017
This is the program code and the out put for my mini project - Dice Roller

A simple Python tool that lets you roll virtual dice right from your terminal using classic tabletop notation (like 3d6 or 1d20+5).

Why it’s handy:
• Roll anything: Easily roll dozens of dice at once—or even imaginary ones like a 38-sided die—without doing mental math.
• Automatic bonuses: Add or subtract modifiers (+ or -) automatically so you always get the right total.
• Learn by building: It’s a fun, straightforward project if you want to practice reading user input and generating random numbers in Python.
